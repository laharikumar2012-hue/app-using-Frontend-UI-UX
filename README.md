# app-using-Frontend-UI-UX
1. Project Requirements
A. Project Title
AI-Powered Social Media Application
Main idea
A social-media platform where users can:
Create an account and log in
View posts/stories
Search for content
Chat with friends
View profiles
Watch reels
Explore images/videos
Use an AI-powered search/assistant
2. Functional Requirements
1. Login Page
The application should provide:
Username/email input
Password input
Login button
Forgot password option
New user registration option
Expected result: User enters valid credentials and reaches the home page.
2. Home Page
The home screen should contain:
App logo/name
User stories
Posts/feed
Like button
Comment button
Share button
Navigation bar
Your Figma design already represents this using the Instagram-style screen.
3. Stories
Users should be able to:
View stories
Add a new story
View multiple users' stories
Move between stories
4. Messages
The Messages screen should contain:
List of conversations
Friend/user names
Profile pictures
Message preview
Request section
Open chat option
Example from your design:
Messages → User → Chat screen
5. Search / Explore
Users should be able to:
Search users
Search posts
Search topics
View images/videos
Explore trending content
Your Figma screen showing the search bar and multiple images represents this feature.
6. Profile
The profile page should display:
Profile picture
Username
Number of posts
Followers
Following
User's posts
Edit profile
Share profile
7. Reels
Users should be able to:
Watch short videos
Scroll between reels
Like
Comment
Share
Follow creators
Your Reels/Friends screen can represent this module.
